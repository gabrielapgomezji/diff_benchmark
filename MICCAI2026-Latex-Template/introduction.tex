\subsection{Gap in the Field}
\begin{itemize}
    \item No standardized benchmark for diffusion MRI prediction
    \item Heterogeneous preprocessing pipelines
    \item Inconsistent feature representations (voxel-wise vs ROI-based), not analysis cross microstructure features
    \item Evaluation protocols not directly comparable
    \item Limited reproducibility and transparency, missing code
    \item Lack of results of the same experiments on other datasets
\end{itemize}

\subsection{Contributions}
\begin{itemize}
    \item Standardized preprocessing pipeline for diffusion MRI
    \item Unified feature extraction strategy
    \item Controlled evaluation protocol (train/test splits)
    \item Comparison of multiple feature representations
    \item Public release of code and benchmark configuration
    \item End-to-end analysis
    \item Integration of both classical and DL models
\end{itemize}
